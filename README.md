# منصة M.A للتدريب والتأهيل المهني - تطبيق أندرويد

## الميزات المدعومة ✓
- ✅ **قراءة صوتية بصوت أنثى**: دعم كامل لـ TextToSpeech مع صوت أنثى متوافق مع أندرويد
- ✅ **الطباعة الكاملة**: طباعة الشهادات والنتائج والملفات
- ✅ **جميع الأزرار تعمل**: إنهاء الاختبار، الحفظ، الملاحة، إلخ
- ✅ **جميع الأسئلة محفوظة**: بدون حذف أو تعديل للمحتوى
- ✅ **متوافق 100% مع أندرويد**: من Android 5.0 فما فوق

## طريقة البناء من GitHub (من الهاتف أو الكمبيوتر)

### الخطوة 1: دفع المشروع إلى GitHub
1. أنسخ كل ملفات هذا المجلد إلى مستودعك على GitHub
2. تأكد من وجود المسارات التالية:
   ```
   .github/workflows/build.yml
   app/src/main/java/com/maplatform/app/MainActivity.java
   app/src/main/assets/*.html (11 ملف)
   app/build.gradle
   build.gradle
   settings.gradle
   gradle.properties
   ```

### الخطوة 2: تشغيل البناء التلقائي
1. في صفحة المستودع على GitHub
2. اذهب إلى تبويب **Actions**
3. اختر "Build APK" من الخيارات
4. اضغط **Run workflow** (أزرق)
5. انتظر 5-10 دقائق حتى ينتهي (سترى ✅ أخضر)

### الخطوة 3: تحميل APK
1. بعد انتهاء البناء، ادخل التشغيل المكتمل
2. انزل لقسم **Artifacts**
3. حمّل `app-debug-apk` (ملف zip)
4. فك الضغط على هاتفك
5. ثبّت `app-debug.apk`

## حل المشاكل

### الصوت لا يعمل
- تأكد من تثبيت "Google Text-to-Speech" على الجهاز
- اذهب إلى Settings → Apps → Accessibility → "Google Text-to-Speech"
- تأكد من تفعيله وتثبيت بيانات العربية

### الطباعة لا تعمل
- تأكد من وجود تطبيق طابعة على الهاتف (مثل "Print to PDF")
- أو اطبع إلى ملف PDF بدلاً من طابعة حقيقية

### البناء يفشل على GitHub
- تأكد من صحة مسارات الملفات
- تأكد من وجود ملف `gradle.properties`
- تأكد من أن جميع ملفات HTML في المجلد `app/src/main/assets/`
