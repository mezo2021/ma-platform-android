## 📖 نبذة عن المشروع

**منصة M.A للتدريب والتأهيل المهني** هي تطبيق أندرويد تفاعلي متطور، مصمم لتهيئة وإعداد الكوادر البشرية لاجتياز المسابقات الرسمية والتأهيلية في المجالات القانونية والرقابية والإدارية والتقنية. يعتمد التطبيق على تقنيات حديثة تجمع بين **WebView** و **Java Native Bridge** لتقديم تجربة تدريبية متكاملة.

### 🎯 الرؤية
> "البيئة التفاعلية المتطورة لإعداد الكوادر"

### 🎯 الأهداف
- 📚 إعداد المتدربين لاجتياز المسابقات الحكومية
- 🎯 توفير محاكاة كاملة لبيئة الاختبارات الرسمية
- 📊 تقديم تقارير أداء تفصيلية لكل متدرب
- 🎓 إصدار شهادات تدريبية محفزة
- 🔊 دعم إمكانية الوصول عبر القراءة الصوتية

## 🚀 دليل البناء والتثبيت

### 🌐 الطريقة الأولى: عبر GitHub Actions (موصى بها)

#### 1️⃣ تجهيز المستودع
```bash
# انسخ المستودع
git clone https://github.com/mezo2021/ma-platform-android.git
cd ma-platform-android
```

2️⃣ إضافة Keystore للتوقيع

اذهب إلى: Settings → Secrets and variables → Actions وأضف:

الاسم الوصف
KEYSTORE_BASE64 مفتاح التوقيع بصيغة Base64
KEYSTORE_PASSWORD كلمة مرور الـ Keystore
KEY_ALIAS اسم المفتاح
KEY_PASSWORD كلمة مرور المفتاح

3️⃣ تشغيل البناء

1. اذهب إلى Actions → Build Signed APK
2. اضغط Run workflow
3. انتظر 2-3 دقائق
4. حمّل APK من Artifacts

---

💻 الطريقة الثانية: البناء المحلي

المتطلبات

```bash
# تأكد من تثبيت JDK 17
java -version

# تأكد من تثبيت Gradle
gradle --version
```

البناء

```bash
# نسخ المستودع
git clone https://github.com/mezo2021/ma-platform-android.git
cd ma-platform-android

# البناء
gradle assembleRelease

# الملف الناتج
# app/build/outputs/apk/release/app-release.apk
```

🎯 دليل الاستخدام

📲 التثبيت

1. حمّل ملف app-release.apk
2. افتحه على هاتفك
3. اسمح بـ "المصادر غير المعروفة" إن طُلب
4. اضغط تثبيت

🎮 الاستخدام

1. افتح التطبيق → ستظهر شاشة البداية
2. اختر المسابقة من الشبكة الرئيسية
3. ابدأ الاختبار:
   · أجب عن الأسئلة
   · استخدم زر 🔊 للقراءة الصوتية
   · تنقل بين الأسئلة بحرية
4. أنهِ الاختبار:
   · اضغط "إنهاء الاختبار"
   · ستظهر نافذة تأكيد أندرويد
5. استلم النتيجة:
   · نسبة النجاح
   · تحليل الأداء
   · إمكانية إصدار شهادة

🔊 استخدام الصوت

· زر الصوت العائم أسفل يسار الشاشة
· اضغط 🔊 → يقرأ السؤال
· اضغط ⏹ → يوقف القراءة

🖨️ الطباعة

· شهادة: اضغط "🖨 طباعة الشهادة"
· سلم تصحيح: اضغط "🖨 طباعة سلم التصحيح"
· اختر طابعة أو "Save as PDF"
